# Semana 12 - Reserva de asiento en sala de cine

Estudiante: Liliam Illanes

## Objetivo
Este programa permite reservar un asiento en una sala de cine de 3 filas por 4 columnas y mostrar el estado completo de la sala en formato de tabla.

## Cómo ejecutar
1. Abre una terminal en esta carpeta.
2. Ejecuta el siguiente comando:
   python reserva_cine.py
3. Ingresa la fila y la columna del asiento que deseas reservar.

## Descripción
La sala se representa como una matriz usando listas anidadas. Cada asiento tiene un valor:
- 0 = libre
- 1 = reservado

El programa valida la posición ingresada y luego muestra la matriz completa con los cambios realizados.
