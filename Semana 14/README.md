# Semana 14 - Promedio de tres notas

Alumna: Liliam Illanes

## Descripción
Este programa resuelve un problema cotidiano: calcular el promedio de tres notas de un estudiante. Para ello se utiliza una función con parámetros de entrada y retorno de valor.

La función `calcular_promedio(nota1, nota2, nota3)` recibe las tres calificaciones, realiza la operación y devuelve el promedio mediante `return`.

## Estructura del programa
- Función: `calcular_promedio(nota1, nota2, nota3)`
- Parámetros: `nota1`, `nota2`, `nota3`
- Retorno: `return promedio`
- Llamada: `resultado = calcular_promedio(nota1, nota2, nota3)`
- Salida: se muestra el promedio final en pantalla

## Cómo ejecutar
1. Abre una terminal en esta carpeta.
2. Ejecuta el siguiente comando:
   `python promedio_notas.py`
3. Ingresa las tres notas.
4. El programa mostrará el promedio final.
